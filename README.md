# GIGUUU 公式HP クローン

A Next.js + Tailwind CSS clone of https://indigo955423.studio.site/

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS

## Sections
1. `Header` — GIGUUU logo, 4 nav links incl. お問い合わせ pill button
2. `Hero` — "Connect the Dots." headline + city image + 1つの出会い copy
3. `Mission` — Our Mission with hands image (magenta/yellow tilted overlay) + green company button
4. `BusinessLineup` — ビジネスラインナップ on cream background + keyboard image + green service button
5. `Footer` — GIGUUU logo, X/Facebook/Instagram icons, nav links

Side gradients (green→cyan on the left, yellow→green on the right) overlay every section.

## Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:3000.
